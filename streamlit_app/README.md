# Streamlit application

This is the production UI layer for SmartHire GenAI. It preserves the visual system supplied in the original UI ZIP and calls the real backend through `streamlit_app/backend.py`.

Run from the project root:

```bat
streamlit run streamlit_app\app.py
```

The project brief specifies Streamlit for the portal interface and deployment. See the root `START.md` for setup and deployment instructions.
